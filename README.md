# DeepSequence

Intermittent-demand forecasting with hierarchical attention (**v1.6**).

## Active package

All product code lives here:

**[`deepsequence_hierarchical_attention/`](deepsequence_hierarchical_attention/)**

```bash
cd deepsequence_hierarchical_attention
pip install -e .
# or
pip install "git+https://github.com/mkuma93/DeepSequence.git#subdirectory=deepsequence_hierarchical_attention"
```

See that folder’s [README](deepsequence_hierarchical_attention/README.md) for architecture, install, residual transformer usage, and the v1.6 bake-off.
